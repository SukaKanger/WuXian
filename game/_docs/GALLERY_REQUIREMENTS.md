# 《雾线》画廊 / 插画交付要求

更新：2026-11-17　适用版本：`V1.28.0 Demo`　引擎：Ren'Py 8.5.3

这份文件是给画师 / 生图执行者的制作规格。代码侧已经准备好槽位，按本文件交付即可直接替换，不需要改界面逻辑。

> **前置条件**：角色立绘 V2 还没定稿。CG 可以先排期，但不要用现仓库 `game/images/chars/` 的旧图当最终设定开画；等 V2 的毛色、伤疤、耳缺、服装和体型确认后，再按 V2 参考图出四张 CG，避免整批返工。

## 二、成图规格

| 项目 | 要求 |
|---|---|
| 画布 | 1920×1080，横版 16:9 |
| 格式 | PNG，RGB（不需要 alpha），sRGB |
| 分辨率 | 72–150 dpi 均可，以像素为准 |
| 文件大小 | 单张建议 ≤ 3 MB；超过 4 MB 先压到 3 MB 内再交 |
| 文字 | 画面内不要烧录标题、对白、署名、水印、边框 |
| 裁切 | 不要自带黑边 / 白边 / 圆角；圆角与卡片由引擎蒙版处理 |
| 风格 | 与现有 `images/bg/` 同一套：低饱和雨林、墨绿 + 暖金、电影感体积光、轻颗粒；避免二次元高亮塑料感 |
| 角色 | 以 V2 立绘定稿为准；毛色、伤疤、耳缺、服装配件必须一致 |

### 安全区（很重要）

画廊缩略图按 `426×272` 做 cover 裁切，主展示区按 `760×860` contain。请把**脸和关键动作**放在：

- 水平 30%–70% 之间；
- 垂直 25%–72% 之间；
- 距四边至少 8% 的留白。

不要把人脸放在最左 / 最右 15% 内，否则缩略图会切到脸。画面底部 25% 会压字幕条与暗角，important detail 不要放那里。

## 三、四张 CG 的内容 brief

### 1. `cg_zhou` — 断崖之后（共同线 · 第 3 章）

- 画面：雨后的断崖，灰狼队长（左脸三道爪痕、左耳缺一角）用一只手把绳头缠在腕上，左臂垂着，肩背有泥与血迹；身后是断掉的旧栈道和雾。
- 情绪：不是英雄式摆拍，是「刚把全队带过来、自己快撑不住」的那一秒。
- 构图：中景，人物略偏右；绳索从画面左下延伸到他手上；远处留出河谷雾。
- 光：黄昏冷蓝 + 营地暖光从右下打过来，脸部半亮半暗。
- 禁止：不要画成肌肉展示、不要加胜利微笑、不要把伤画成装饰。

### 2. `cg_lan` — 银纹（蓝羽 · 第 9 章）

- 画面：蓝狼向导蹲在河边，把湿透的地图摊在膝盖上；地图上那条断线用银笔重新描过；旧队徽挂在指间。
- 情绪：他刚承认「上一支队伍只剩我一个」之后的安静，不是哭戏。
- 构图：近景半身，人物偏左，地图占右下；河面反光在画面下方。
- 光：阴天散射 + 水面冷反光；脸部不要打平光，保留眼窝阴影。
- 禁止：不要加雨滴特效糊脸、不要把地图画成现代印刷品。

### 3. `cg_bai` — 灯下（白砚 · 第 18 章）

- 画面：白砚（白虎队医）在旧站值夜，桌上一盏旧矿灯、摊开的药盒、少了一半的药瓶；他正把最后一片药放进别人的剂量纸，自己的水杯空着。
- 情绪：手很稳，但灯下的影子很薄；观众要能看出「他在减自己的药」。
- 构图：中近景，人物居中偏右，灯在左下；桌面占下方 1/3。
- 光：单一暖矿灯 + 冷月光从窗缝补背光；高光只落在手和药瓶。
- 禁止：不要画成医院宣传照、不要加明显十字标志。

### 4. `cg_qing` — 守站人（青岩 · 第 24 章）

- 画面：青龙学者站在废弃气象站的铁架下，怀里抱着样本箱，箱盖半开；他导师的半页记录用透明袋装着，压在箱侧；身后是停在半空的索道轿厢。
- 情绪：他终于拿到能证明导师那篇论文的东西，但站里已经没有活人。
- 构图：中景，人物偏左，铁架与索道形成纵深；右侧留出旧站控制台。
- 光：黄昏侧逆光 + 铁锈暖色；脸不要全黑，保留眼睛高光。
- 禁止：不要加现代电脑屏幕、不要画成科幻实验室。

## 四、缩略图与圆角

正式图交付后，画廊还需要两张派生物：

1. `gthumb_cover_<id>.png`：从 1920×1080 按 `426×272` 做 cover，焦点按上面的安全区手动定，保证脸完整；
2. 8px 圆角蒙版：4×SS 抗锯齿，四角 alpha=0，不要描边。

当前缩略图命名与代码：

```text
game/images/ui/gthumb_cover_cg_zhou.png
game/images/ui/gthumb_cover_cg_lan.png
game/images/ui/gthumb_cover_cg_bai.png
game/images/ui/gthumb_cover_cg_qing.png
```

替换后跑一次 lint，再进游戏确认六卡同高、同边距、脸不偏。

## 五、验收清单

- [ ] 1920×1080、RGB、sRGB、无 alpha、无文字 / 水印 / 边框；
- [ ] 脸在水平 30%–70%、垂直 25%–72% 安全区；
- [ ] 四张并排时色温、对比、颗粒一致，不出现一张偏蓝一张偏橙；
- [ ] 底部 25% 没有关键信息；
- [ ] 缩略图 426×272 下脸完整、不歪、不切耳朵；
- [ ] 文件名与 `VN2_GALLERY` 的 `id` 一一对应；
- [ ] `lint` 0 error，画廊页六卡几何一致；
- [ ] 交付时附一张四张并排的 contact sheet，方便一次比对。
