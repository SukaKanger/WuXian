## 四、C 批已知风险

1. **跨章咬合只到叙事层，没有持久化判定**：ch07 的残片/拓片/空手、ch09 的三种天线位置、ch02 的三种营地位置，都无法写进旗标（12 个旗标全被后续读点锁定，schema 禁改），所以后果靠"三态并行旁白 + 呼应句"实现。玩家选树下干地时，ch04 的回声对应感偏弱（hedged 叙述）。
2. **ch04 缺觉后果只落在夜里征兆**，没有在 ch05 落"次日掉队"句（ch05 不属本组可改范围）。
3. **字数已越过 B 批单章预算**：带容器的 9 章现为 4,055–4,605 字/章，属 C 批设计使然，不是注水——每组容器都有独立目标与后果。
4. **好感仍在缓慢累积**：C 批每组容器新增 3–4 点（单次 1–2），比 B 批克制；但"真结局 60 门槛是否被过早满足"这个结构问题仍未解决（需改阈值或回调既有幅度，属禁改范围）。
5. **单周目时长按 200 字/分是 6.0h，按 240 字/分是 5.0h**：两个换算口径差 1 小时，实际体感受阅读速度影响，实机跑会给出更可信的数（见 `ROUND7_PLAYTEST.md`）。
