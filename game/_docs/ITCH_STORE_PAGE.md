## 短描述

《雾线》是一款兽人向视觉小说 Beta 版。四人小队在二十七天内穿过一张地图上没有的雨林，寻找一座从地图上消失的旧站。共同线 + 三条恋爱线，选择会改变信任与结局。

## 长描述

一支四人小队，二十七天，穿过一张地图上没有的雨林，去找一座从地图上消失的旧站。

灰狼队长、蓝羽、白砚、青岩——四个人带着各自的过去上路。雨一直没停，旧站却在地图上留下了不该留下的痕迹。你要决定谁走在前面、谁留在后面，也要决定自己最后要不要走出这片林子。

- 类型：兽人向视觉小说 / 叙事冒险
- 引擎：Ren'Py 8.5.x
- 语言：简体中文
- 当前版本：V2.28.3 Beta
