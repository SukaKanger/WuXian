## 1. 口径修正（本轮硬约束）

1. **不新增具名角色。** 主卡司就是 6 人：老周（玩家）、蓝羽、白砚、青岩、阿瑞、十七。阿瑞/十七只做 NPC，不进恋爱线、不进结局判定。
2. **扩线不靠新 NPC 撑时长。** 内容增量只能来自：玩家与蓝羽/白砚/青岩的关系推进、营地与休息、探索、副本、共同线回扣。
3. 一切"需要一个人出场才能交代"的信息，改用下面这五种载体之一，**不得新增可交互常驻立绘**：

| 原本要用的人物 | 替代载体 |
|---|---|
| 公司调查员 | 无线电杂音、摩斯式编号、烧了一半的登记表 |
| 旧队友（蓝羽那支队） | 队徽刻字、三股绳与四股绳的差别、防水袋里的名字 |
| 导师（青岩） | 半页记录、署名笔迹、样本箱内衬上的手写标签 |
| 部落长老（阿瑞） | 远景背影 + 一句转述、骨珠刻纹规则、交易条件 |
| 守站人（十七） | 只以"石门后的声音/骨珠/背影"出场，仍是 NPC，不加恋爱线 |

4. 不写"无论怎么选都会死同一个人"式的绝望；每个刀点必须给玩家可操作的应对。

## 2. 容量与时长模型（唯一换算口径）

- 阅读速度基准：**200 字/分钟**（含点读停顿，不配音）。
- 换算：1 小时 ≈ **12,000 字**；6 小时 ≈ 72,000 字；8 小时 ≈ 96,000 字；4 小时 ≈ 48,000 字。
- 单周目 = 共同线 15 章 + 本线 3 章 + 结算/结局 4 章 = 22 章。
- 现状：单周目约 **12,000 字 ≈ 1 小时**。
- 目标：单周目 **72,000–96,000 字**（主线 6–8h）；solo 线 4h 以上。

**章级预算（本轮统一执行）**

| 章型 | 字数/章 | 章内节点 | menu 数 |
|---|---|---|---|
| 路线章（ch16–ch18 / ch19–ch21 / ch22–ch24） | 2,000–2,500 | 6–8 | 3 |
| 共同线章（ch01–ch13、ch15） | 2,500–3,500 | 7–9 | 3–4 |
| 锁线章 ch14 | 1,200–1,500 | — | 1（四选一） |
| 结算章 ch25 | 2,000–2,500 | 6 | 2 |

menu 密度：**每 700–800 字一个 menu**；每个选项必须有可被后文读到的后果（好感 / 既有旗标 / 分支台词三者至少一个）。

## 3. 章内节点渲染规范

- 仍是**一个章一个 label**（`label chNN:`），不新增 `chNN_x` 顶层 label，不动 `core/20_router.rpy`。
- 节点以注释分隔，便于后续按节点增删：
  ```renpy
  # --- 节点 3/7 · 收法（menu） ---
  ```
- 节点内部只用：`nar`（第二人称旁白）、`think`（玩家内心）、`zhou`（玩家台词，名牌显示玩家名）、三名可攻略角色台词、`menu`。
- 场景只许用 `bg forest / firelight / cliff / marsh / gate / hall`；环境音只许 `vn2_amb("rain" / "fire" / "forest" / "tunnel")`。
- 立绘调度：单人对白默认不 show 玩家自己（`zhou` 只在群像/背影出现）；角色表情用 `vn2_show("lan", pos="left", ...)` 的既有写法，**不新增表情名**。
- 章首固定三件套：`scene bg X with slow_fade` → `$ vn2_enter_chapter("chNN")` → `call vn2_title_card(disp, "标题", "第 D 天 • 路线标签")`；章末 `$ vn2_hide_all(trans=dissolve_soft)` + `$ vn2_leave_chapter()`。

## 4. 状态约束（不得违反）

- 好感只写 `vn2_aff_add("lan" / "bai" / "qing" / "ari", N)`，单次 2–6。
- 旗标只能用既有集合，**不得新增旗标键**：
  `trust_team / close_lan / lan_map_fixed / saved_bai / bai_treated / know_qing_secret / qing_trusted / station_key / evidence_kept / evidence_copied / trust_shiqi / ari_helped`
- **每章既有的旗标写入必须原样保留**（扩写只许增加节点，不许删掉原有写入点）。
- 路线章里**不得给他线写恋爱线好感**（跨线泄漏已在 R6 修完，不要回退）。
- 不改阈值、不改判定、不改结局 key、不改存档 schema、不改 CG 与立绘。
