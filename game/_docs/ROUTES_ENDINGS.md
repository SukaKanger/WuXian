## 共同线（第 2–7 章，玩家角色）

**核心冲突**：你知道这座站，而且十年前亲手送过人进去。你要在「带人出去」和「不再进去」之间选，而队伍每一次把绳、把后背交给你，都是在替你重复这个选择。
**递进**：ch03 断崖用一条胳膊换全队过去 → ch04 夜哨说出前任队长「六进四出」→ ch05 绳结（越拉越紧，松不了）→ ch06 雨幕走散，谁回头 → ch07 第一块站牌，你承认「十年前送人进来没送出去」。
**冲突点**：ch03 你可以先救自己、先固绳、或者先去抢电台——三个选项决定队伍后面愿不愿意把命交给你。
**结局落点**：共同线 E01 里你停在公路边，把砍刀和那个结留给队伍，自己走回林子；E02 里你终于说出「这一次，算我送出去了」。

**核心冲突**：蓝羽要找姐姐，而所有线索都指向「别进来」。他要的是一个人，队伍要的是一条路。
**递进**：ch09 银纹（站里出来的东西拔不掉）→ ch10 地图被制图笔改过 → ch11 信标有人回「还活着」→ ch12 旧营地的圈加一横记号与泡烂笔记 → ch14 电台喊他的名字，回「别进来」。
