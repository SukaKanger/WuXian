# 雾线 WuXian 1.28.22 Beta · 剧情修复记录

> 目标：按玩家反馈修中段节奏、选项后果、路线透明度、阿瑞假路线、结局换皮与伤口连续性。
> 约束：不改任何 CG；已发布的 1.28.21 旧存档必须继续可读。

## 1. 中段导演剪辑版

新增 `game/story/directors_cut.rpy`，ch05–ch14 在章节开头按 `vn2_story_mode` 分流：

- 新档 / 章节选择：`cut`，进入剪辑版。
- 旧档停在章节中途：继续旧脚本，不破坏当前节点；下一章开头自动切剪辑版。
- `classic` 保留旧脚本入口，便于回看/调试。

剪辑版把“赶路 → 三选一 → 扎营 → 再选一次”压成“一章一个冲突、一章一个真正有后果的选择”：

| 章 | 保留的核心选择 | 写入的状态 |
|---|---|---|
| ch05 绳结 | 怎么练绳 | 蓝羽 / 白砚 / 青岩好感 |
| ch06 雨幕 | 先往哪边动；火圈外怎么对白砚 | `trust_team`；白砚 / 蓝羽 / 青岩好感 |
| ch07 站牌 | 站牌底下怎么处理 | `lan_map_fixed`、青岩好感、白砚好感 |
| ch08 沼泽 | 救不救阿瑞；深水先顾谁 | `ari_helped`；阿瑞明确“不跟你们走” |
| ch09 银纹 | 碰不碰银纹 | `vn2_unlock_cg("cg_lan")` |
| ch10 地图 | 这一笔怎么处理 | `lan_map_fixed`；当面摊牌 |
| ch11 信标 | 信标怎么回应；最后一响陪谁 | `close_lan`（蓝羽交底） |
| ch12 旧营地 | 杆子落下来先做什么 | `saved_bai`（你救过白砚的手） |
| ch13 分岔 | 走哪条路；夜里注意到什么 | `know_qing_secret`；章末逐条说破三线交底 |
| ch14 锁线 | 原有四选一 | 增加“已交底 / 未交底”和结局走向提示 |

## 2. 路线与结局透明化

- `vn2_lock_options()` 增加 `bond / bond_text / bond_hint`；锁线屏显示承诺状态。
- 锁线屏底部新增：
  - 同行：本线好感至少 40 + 本线承诺。
  - 独行：进了这条线，但没把最后一句话交出去。
  - 第七天：十七信任 + 带出证据 + 本线好感至少 60 + 本线承诺。
- `vn2_lock_pick()` 在好感达标但未交底时弹提示。
- 笔记本“本局”只显示蓝羽 / 白砚 / 青岩三条好感，阿瑞单独标为“向导，非攻略角色”；新增“同行条件”区块。
- 主菜单进度标签改为“正文章节”，解释 25 的分母（结局章 ch26–28 不计入正文章节）。

## 3. 阿瑞假路线

- ch08 剪辑版让阿瑞明确说“我不跟你们走。我有自己的线，也有自己的账”，旁白点明“这不是一条可攻略的路线”。
- 笔记本不再显示阿瑞好感条；总好感只统计 `VN2_ROMANCE_KEYS`。

## 4. 结局不再换皮

- `ch26` 六个路线收束分支独立：蓝羽 / 白砚 / 青岩 × 同行 / 独行，各自有独立动作和意象。
- `ch27` 路线收尾按路线与是否同行分开写，不再共用一句“他看你的眼神不像告别”。
- `ch28` 八个后日谈原本独立，未动。
- 八个结局 key 全部保留：`lan_together`、`lan_alone`、`bai_together`、`bai_alone`、`qing_together`、`qing_alone`、`sealed`、`seventh`。

## 5. 青岩线 bug 修复

`qing_trusted` 原先只在章节选择回填时写入，正常新游戏里没有落点，导致青岩线无法进入“同行 / 第七天”。

- `vn2_route_bond("qing")` 现在接受 `know_qing_secret` 或 `qing_trusted`。
- ch22 青岩主动摊开半页记录时补写 `qing_trusted`，笔记本“青岩还压着箱底”会随之更新。

## 6. 伤口连续性

ch05 剪辑版补一句设定：左肩是旧伤，右手背是前天在桥上裂的新口子，两处都还没好。后续文本按“左肩旧伤 / 右手新伤”理解，不再让读者以为是同一处漂移。

## 7. 存档兼容

- `VN2_DEFAULT_VALUES` 新增 `vn2_story_mode`（默认 `"cut"`）与 `vn2_story_rev`。
- `vn2_repair_state()` 在 `after_load` 中补齐缺失 default，旧档自动获得剪辑版开关。
- 未删除任何结局 key、未重命名章节 label。
- 旧档若停在章节中途，继续旧脚本；下一章开头进入剪辑版。
