## 2. 甜点验收（STORY_CANON v3 的落地细则）

一场合格的甜点，四条全中：
1. **非任务**：不为解决问题而存在（递药、包扎、分干粮这类功能性照护单独出现不算甜点，除非同时具备第 2 条）。
2. **至少含一项**：偏心（同样的事对别人不做 / 只给你）· 记得（记住你随口说过的小事、你的旧伤位置、你不吃的味道）· 靠近（不必说话的身体距离、替你挡风、并排走时不自觉放慢）。
3. **有前置触发**：写在某个选项分支内，或包在既有旗标的 `if store.xxx:` 块里。**不得新建 store 变量**（会破坏存档兼容）。
4. **150–300 字**，一场一段，不要写成三小段分散。

**三线甜味必须不同：**

| 线 | 甜味语汇 | 禁止 |
|---|---|---|
| 蓝羽 | 绳（结/收尾/握绳头）、不经意的触碰（手背、手腕、尾巴扫过）、名字（喊你名字而不是「队长」） | 不说情话、不告白 |
| 白砚 | 手（握腕、暖手、按着不让你动）、药（把自己的份额给你、记得你过敏的那一味）、被照顾（他允许你照顾他） | 不撒娇、不哭 |
| 青岩 | 食物（掰一半塞你口袋、记得你不吃苦的）、记录（把你的名字写进本子/划掉重写）、并肩（窄处走外侧、不说话坐一起） | 不背诗、不突然哲学 |

## 5. 甜而不腻的三条写作纪律

- 甜点**不解释**：不写「他心里其实……」，只写手上做了什么、距离变了多少。
- 甜点**不重复语汇**：同一章两场甜点不许用同一动作（不能两场都在暖手）。
- 甜点**不解决冲突**：甜点不推进任务，甜完立刻回到任务语境；刀点前一场甜点要留"没说完的半句"，让刀点来切断它。
