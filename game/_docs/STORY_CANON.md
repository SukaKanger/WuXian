# 《雾线》故事口径（2026-11-17 定稿，v3）

## 一、四人小队 = 玩家 + 三名可攻略角色

| 位置 | 角色 | 说明 |
|---|---|---|
| 玩家 | **老周**（灰狼，42 岁） | 左脸三道爪痕、左耳缺一角；队长，队伍里唯一有野外带队经验的人。名字由玩家开局自填（2–10 字，默认「队长」）；旧稿里的「老周」是这个人，**不是独立 NPC，也不是第四条恋爱线** |
| 队员 | 蓝羽（蓝狼，26 岁） | 向导；上一支队伍的幸存者；地图上那条断线是他心里的结 |

| 队员 | 青岩（青龙，24 岁） | 学者；导师死在遗迹里；样本箱比命重 |

## 二、NPC（现阶段只做这 6 个角色，其余后续补）

- **阿瑞**（红狐，20 出头，部落向导）：支线人物，不进恋爱线，不进结局判定；好感只影响支线与交易。
- **十七**（黑豹，年龄不明，遗迹守门人）：悬念角色，不可攻略；只提供真结局所需的「十七信任」。

## 三、路线结构：并行，不串联

- 第 1–13 章：共同线。三名可攻略角色的好感与秘密都在这里埋。
- 第 14 章：锁线，四选一——蓝羽 / 白砚 / 青岩 / 独自进入。
- 第 15 章：门口，锁线后的共同场景；守门人提出交易。
- 第 16–24 章：三条线**并行分支**，每条线各 3 章专属内容；玩家一次只走本线的 3 章。**不再按角色切成 ch01–07 老周、ch08–14 蓝羽、ch15–21 白砚、ch22–28 青岩 这种顺序四段**。
- 第 25 章：一次性结算结局；第 26–28 章：结局演出与后日谈。
- 章号是**内容目录编号**，不是单周目顺序。单周目实际读 22 章：1–15 + 本线 3 章 + 25–28。存档与章节页按「蓝羽线 · 第 3 章」显示，不显示跳号。
- **天数口径**：故事实际跨度为 **27 天**；`28` 是内容目录的章节总数。第 28 章「后日谈」发生在第 27 天之后，不显示为「第 28 天」。UI、章节页、标题卡、商店文案一律按此口径，不得再把 ch28 标成第 28 天。
- 结局 8 个：蓝羽 / 白砚 / 青岩 各「同行 / 独行」6 个 + 封口 + 真结局「第七天」。
- 判定优先级：封口 / 独自进入 > 强制独行 > 真结局 > 同行 > 独行；8 个结局按 3 条路线各 2 个 + 封口 + 第七天分配。

## 四、叙事节奏：甜、刀与伏笔

- 内容目录设 6 个刀点（第 6、10、17、20、23、25 章）和 7 个甜点（第 2、3、13、16、19、22、28 章）。
- 单周目实际经过 4 个刀点（第 6、10、本线的 17/20/23 之一、第 25）与 5 个甜点（第 2、3、13、本线的 16/19/22 之一、第 28）。
- 每个刀点至少两处前置伏笔，其中至少一处在可选副本；刀后一章内必须回收一次。
- 刀点必须给玩家可操作的应对，不写唯一解式的绝望，不写「无论怎么选都会死同一个人」。
- **甜点验收（扩写后按此执行）**：甜点不能只是递药、包扎、分干粮这类功能性照护；每场至少包含「偏心 / 记得 / 靠近」中的一项，且由前置选择或资源状态触发。每章至少一场 150–300 字的非任务甜点，甜点里建立的习惯、信物或承诺必须在后文被刀点使用或回收，禁止空降式发糖。
- **甜与刀的比例**：单周目 4 个刀点不变；扩写到 6–8 小时后，甜点密度提高到每 2–3 章一场，而不是只靠原有 5 个甜点撑全程。每场刀点前保留一场可回看的甜点，刀点后一章内给一次回甘。
- 四个反例不进入本稿：《药》式缺药断药、《绝望的解决手段》式只承认牺牲、《城堡》式副本只惩罚、《莫梭提丝》式反转否定玩家此前全部选择。

## 五、探索层（不占章号）

- **地图**：4 区域 16 节点——雨林入口（营地/渡口/旧栈道/塌方矿道）、河谷（沼泽/猎人废营/瀑布/药草坡）、旧站（气象站/哨塔/索道/补给洞）、遗迹（洞口/石廊/守门人石门/断崖）。节点五类：主线金、采集绿、支线蓝、副本红、营地白。
- **时间**：每天晨、午后两个行动时段，夜间回营地；移动/采集各耗 1 时段，副本 1–2 时段。单周目约 22 个自由时段。
- **物品栏**：12 通用格（4×3）+ 3 信物格；食材叠 5、药品叠 3、工具与信物 1；五页签（食物/药品/工具/信物/样本）；操作只有使用/给予/丢弃，给予 +2 好感并解锁一句专属台词。
- **食物**：采集节点每天一次产 1–3 份食材；夜间两顿饭，每顿 2 食材出 2 熟食；四人每晚各 1 份；给对偏好 +2、给错 0、没分到 −2 且次日体力 −1、全员吃饱次日体力 +1；不设饿死。
- **副本**：4 个红色节点，3–5 场戏、10–20 分钟、主动进入、不改主线走向；每个至少一收益一选择一伏笔；不设战斗，失败只损资源可撤退。
