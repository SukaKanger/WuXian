# 雾线 WuXian — V2.28.4 GA

> 2.28 线最后一版。不是把 Beta 标签撕掉了事：三份 2.28.3 审查里的阻断项、界面元叙述、CG/文本错位和模板句密度，这一版一起收掉。

## 1. 这版改了什么

### 1.1 审查阻断项

- `ch26.rpy:53` 旁白 POV 串台：`把我的手翻过来` → `把你的手翻过来`。
- `ch18.rpy:18` 同一句蕨叶描写写了两遍：删前句，保留带“先前的人压过”的后句。
- `ch27.rpy:22` 路线内部术语漏进旁白：`你和本线同行的人往外走` → `你和同行的人往外走`。

### 1.2 玩家界面去元叙述

- 第 14 天锁线屏：删掉“需要好感 25 / 当前 23（还差 2）”、`承诺：已交底/未交底`、底部 40/60 同行条件表；未达标项只显示“这一步还没走到。”
- 笔记本：删掉三条好感条、“同行条件”页、“阿瑞：非攻略角色”说明；只保留当前章节、进山天数和已记下的情报。
- 路由通知：不再弹“结局会先落独行”“还差 N 点好感”；锁线达标后静默进入路线。
- 存档卡、章节页、画廊：删掉好感摘要、总好感统计；未解锁结局不再提前显示结局名和路线。
- 设置页：删掉“全部设置即时写入 persistent”“卡片从左划入 0.40s”等实现自述。
- 加载提示：删掉 `persistent` 这种引擎词，改成“CG 解锁后会留在画廊里”。

### 1.3 第二轮文本润色

- 不是继续机械删词。保留有效比喻，改具体动作与停顿。
- `指腹` 54 → 29 处；`停了一息` 22 → 17 处；`一层压一层` / `一串压一串` 在 `ch26` 清掉；`ch07` 的长感官清单拆成两段。
- 定向修了 `ch01 / ch07 / ch13 / ch16 / ch18 / ch21 / ch23 / ch26 / ch27 / endings` 的模板动作、过度精确和替读者猜心理。
- 保留：`ch01:187`“不像木头，像铁”、`ch07:41`“像有人拿刀尖压出来的记号”、`ch27:39`“下一段我走前头”、`ch28:66`“雾在他身后合上，像一扇门”。

### 1.4 CG 与文本对齐

- `lan_together`：正文“两道影子压在泥上，一前一后，谁也没并到谁旁边”与并肩 CG 冲突，改为“隔着半步，最后并到一处”。
- `qing_alone`：正文“抱起箱子”与 CG 里空手站立的青岩冲突，改为把样本箱留在脚边、登记簿留在柜面。

### 1.5 版本与构建

- 外部版本：`V2.28.4 GA`；内部版本 `20260004`。
- `build.version = 2.28.4`；发行目录 `WuXian-2.28.4`。
- 安装包 `AppVerName` 去掉 Beta，补 `VersionInfoVersion=2.28.4.0`。
- 角色台词 541 行、`voice` 引用 482 条，与 2.28.3 逐条一致，0 改动，不需要重配音。

1. **静态 / lint**：Ren'Py 8.5.3 lint，0 error / 0 warning；2,031 对话块、105,725 字符、100 菜单、59 图像、56 屏。

## 4. 已知限制

- Windows 安装包使用项目自签名证书 `CN=WuXianSukaKanger0913` + Sectigo 时间戳；自签名根不受公共信任，部分机器仍会提示“未知发布者”。
- APK 使用项目自有 keystore 签名，签名主体 `CN=WuXian`，与 2.28.2 / 2.28.3 一致。APK 与 Windows 安装包不是同一签名主体，这是两条历史升级链的现状，不是本轮新引入的问题。
- 三条独行结局结构仍保留（产品取舍：八结局画廊完整），未合并为通用独行。
- 本轮文本仍是定向修补，不是 30 个 story 文件的全书重写；Max 审查里的 A 文本 2.8/5 没有在新版重新抽样，整书语感仍是下一轮的事。
